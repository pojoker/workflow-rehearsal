本库将锚点向上爬一层，登记其**生成器**。触发词：**「跑光模块收割」**。

## 与聚变库的结构差异（重要）

聚变域是**采购登记型**：T1 稳态流，周级扫描。
光模块域是**披露登记型 + 物质流**：私营企业无采购/审批登记，T1 集中在
资本市场事件的强制披露时刻（IPO 问询、并购问询、定期报告、互动平台）——
**脉冲流**。例程因此不同：

- 稳态部分（月级）：S04 互动平台按公司名过滤、S06 财联社、S07 海关月度数据
- 脉冲部分（事件驱动）：S02/S03 审核项目页——每一轮问询回复是一批新 T1，
  信息密度高于年报（监管逼问出的产能/客户/订单粒度，公司主动披露不会给）
- 定期部分（季度）：S01 拉覆盖名单的定期报告与公告

测算的共同天花板，写报告与拆报告时都应显式声明。
