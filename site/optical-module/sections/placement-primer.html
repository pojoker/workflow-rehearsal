零基础入口先看位置，再看缩写
Placement primer · 光学放在哪里

Front-panel、NPO、CPO：都是“电变光、光变电”，主要差在放置位置

先把交换 ASIC 想成机器的大脑，把光引擎想成电信号和光信号之间的翻译器。三种方案不是三个不同任务，而是把同一个翻译器放在不同地方。位置变化以后，高速电线要走多远、光纤从哪里开始、谁负责散热和维修，也会跟着变化。

Front-panel

翻译器放在机器前面板

常见实例是 OSFP、QSFP-DD 等可插拔模块。ASIC 先用高速电信号穿过封装、主板走线和连接器到达前面板模块，模块再把电变成光送进光纤。

好理解的价值：模块边界清楚，整只模块通常是一个独立产品和更换单元。
代价去向：高速电路径较长，连接器、走线、模块功耗和前面板散热要共同闭合。
边界：“可插拔”不自动等于带电可换、无流量中断或所有人都可维修。
NPO / OBO

翻译器搬到 ASIC 附近或主板上

NPO 常展开为 Near-Packaged Optics，OBO 是 On-Board Optics。共同直觉是：不再把高速电信号一路送到前面板，而是让光引擎更靠近 ASIC，然后用光纤把信号带到机箱边界。

好理解的价值：潜在缩短高速电路径，缓解电损耗和面板密度压力。
代价去向：光纤管理、冷板、安装返工、校准和维修更多进入主板与系统设计。
边界：NPO 没有一个通吃所有产品的毫米线，也不自动等于 socket、LPO、无 DSP 或现场可更换。
CPO

翻译器进入 ASIC 的一级封装边界

CPO 是 Co-Packaged Optics。以本项目采用的 OIF 边界理解，光引擎与 Host ASIC 位于同一 first-level substrate；它们仍可以是不同对象，并不意味着做成一整颗不可分的芯片。

好理解的价值：高速电路径进一步靠近 ASIC，有机会缓解 package I/O 与系统密度压力。
代价去向：封装、热、内部光纤、光源、故障影响范围和维修权限变成系统级问题。
边界：CPO 不自动规定 socket/焊接、集成/外置激光器、DSP 架构或能否现场维修。

一句话记忆

Front-panel：光在机箱前面开始→NPO/OBO：光在主板、ASIC 附近开始→CPO：光在 ASIC 的一级封装边界开始
“更近”只说明责任迁移，不说明赢家。电路径可能缩短，但光纤、散热、装配、故障隔离和维修会更深入系统。最终要比较的是同一速率、距离、温度、可用性和维护目标下的整体结果。
正式知识边界：KN010 已正式确认 OSFP 前面板实例与 OIF 3.2T CPO 实例具有不同机械边界；NPO/CPO 更完整的 attach、功耗、可靠性和服务性比较目前仍是候选研究，不能从本页类比直接晋升。
