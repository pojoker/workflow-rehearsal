## ② 数据模型

**tree.yaml** — 节点 `{id, 名称, children}`；叶=格子 `{cell_id, 工艺备注, 路线∈{电信气密, 数通COB/硅光, 共用}}`。顶层两个block：`universe`（分母定义：A股光学光电子+半导体全体、冻结日期、扩容=升版本号且新增行带出处）和 `观察名单`（宇宙外点的合法名录：联亚、全新等台股外延）。**schema里没有锚字段——结构层想挂证据都挂不上**（L2的解靠字段存在性，不靠纪律条文）。

**points.csv** — `point_id, 公司(唯一), cell_id, 状态∈{生产中,在建,传闻,宇宙外观察}, 上市标签∈{A股,美股,港股,台股,未上市私企,未解析}, 命中引语(±40字逐字), 锚点URL, 检索日期, 判定等级, 判定会话日期`。`{未上市私企}≠{未解析}`：两个枚举值，伪值无处表达。**点的三条合法准入路径（全部要求引语+锚，无空引语后门）**：①语料命中+判定闸（引语=语料原文）②宇宙外观察点（须在 tree 观察名单列名，锚=公司官网/上市文件/年报URL）③panorama 已判层历史迁移（判定会话日期=历史会话）。——第②条是修C的准入矛盾：台股外延能入图，且不豁免证据字段，只豁免分母成员资格。

**edges.csv** — `edge_id, 供方, 需方(名称原文保留), 供方point_id, 需方point_id ∈ points∪{ANON,EXT}, 数值类型∈{占比,金额}, 数值, 单位(金额行枚举必填:元/万元/百万美元…), 占比或金额原文, 财年, 边等级∈{实边,半边,推断A,推断B,推断C}, 证据文件, 锚点, 验证状态, 备注`。**ANON**=匿名对手方（33条半边槽位的合法位置，解匿成功后回填真point_id）；**EXT**=宇宙外终端客户（NVIDIA/Google/Cisco——不占BOM格，不造伪节点）。多期打包行（实测约84条）：解析列可空+备注"待展开"+原文列必填，不销毁信息；边×期展开留给未来会话，archive里的 edge-timeline.csv（148行）是半成品接续点。

**triage.csv** — 处置台账，append-only。`hit_id(公司+格子+引语前缀hash), 公司, cell_id, 来源∈{扫描,线索,人工}, 引语或线索摘要, 处置∈{已入点,已入边候选,驳回-碰撞,驳回-非本格,驳回-证据不足,待判}, 理由, 会话日期`。**只有判定闸会话写入，scan.py 只读**：出队列时剔除已处置 hit → 队列单调收敛，同一误报一生只分诊一次；`待判`行=持久队列，断线不丢；`驳回`行=可记账的产出。这一个文件同时修掉C的队列腐烂、注水KPI、断点丢工三个死穴（嫁接A的inbox+B的judged.csv，压成一件）。

**words.txt** — 每行固定四列 `词|cell_id|排除正则|最小上下文要求`，后两列可空但竖线必须在——每个新词被迫过一遍碰撞检查（B案"空也要显式写"的嫁接）。种子规则直接固化已付学费：`TIA`排TIAN\w/CONSORTIA/INITIA、`TOSA`排AUTOSAR、`隔离器`排数字隔离器。

**scan.py** — 两种模式。`python scan.py`：pdftotext+词表×语料→净命中队列（对比triage剔除已处置）＋顺带全量不变量；`python scan.py --check`：只跑不变量，<10秒。**七条不变量**：①分母（corpus/每文件必有_frozen行，缺即硬失败）②端点闭合（edges两端∈points∪{ANON,EXT}）③自指（points中上市公司且状态≠宇宙外观察 ⇒ 必∈_frozen；宇宙外观察点必在tree观察名单）④单位量级（金额行枚举单位必填+换算后量级阈值，**阈值自含，不引营收外部数据依赖**；占比行∈(0,100]）⑤枚举（四表全部枚举列非法值拒绝）⑥文件白名单（根目录文件集恰好=白名单；archive/与refs/之外新增.md即失败——A案最好的一笔，原地嫁接）⑦triage一致性（处置=已入点的hit必须真在points里）。

**render.py** — yaml+csv→out/全景.md+.html，幂等全量重建，**确定性渲染（无墙钟时间戳）**：页脚印 数据截至日=max(检索日期)+宇宙冻结版本+覆盖率(已判点/命中数)+**空叶格清单**（结构债持续曝光，嫁接B案gaps思想）。`--verify`：重渲到临时目录与out/比对，手改必拒。

**钩子（闸接扳机，修B案同款空头支票于未发）** — `.githooks/pre-commit`：`scan.py --check && render.py --verify`；`.githooks/commit-msg`：提交信息必含 `产出: +N点 +M边 驳回K` 或 `维护:` 前缀。会话1执行 `git config core.hooksPath .githooks` 入库。两个钩子合计秒级、确定性、报错点名到行——快到没有理由 `--no-verify`。

## ⑤ L1-L8 防复发机制表（每条都有执行结构，无一条只活在文档里）

| 教训 | 机制 | 强制点 |
|---|---|---|
| L1 范式颠倒 | 树手写在最上游；点只有三条准入路径且全要引语+锚；边端点闭合（ANON/EXT是显式豁免**值**，不产生新点）——"从边收割点"在schema上无法表达 | 不变量② |
| L2 常识误杀 | tree.yaml schema无锚字段，结构层物理挂不上证据；锚字段只存在于points/edges两处 | 字段存在性（schema即政策） |
| L3 编排放大 | 恰好2脚本、前台秒级、单线程，仓库无nohup/subagent容身处；token只在段2；单位拆列+枚举+量级断言；公司名唯一、归并只走人工会话；**判定后立即--check** | 不变量④⑤ + pre-commit |
| L4 无分母 | 分母是运行前置条件（缺_frozen行硬失败）；自指断言；边界声明+覆盖率+数据截至日+空叶格清单印在产品页脚——**腐烂可见** | 不变量①③ + render页脚 |
| L5 流程自嗨 | 根目录文件白名单+全仓.md白名单是**不变量**（第8个文件=红灯）；产出三数由commit-msg hook强制；驳回记账即产出；评价闭环唯一=用户审diff | 不变量⑥ + commit-msg hook |
| L6 数据渲染不分 | out/由render幂等重建、确定性渲染、无中间JSON层；pre-commit跑--verify，手改必拒；刷新=一条命令 | pre-commit hook |
| L7 伪值碰撞 | {未上市私企}≠{未解析}封闭枚举；words.txt排除列强制存在；判定闸产品类别必答；**驳回-碰撞行沉淀进triage，scan永久跳过——同一误报一生只分诊一次** | 不变量⑤ + triage机制 |
| L8 BOM结构错 | 树v2独立会话，验收清单=已知三错；宇宙外观察名单给台股外延合法入口；空叶格印在产品上持续曝光；改树免锚、成本=一次diff，不会将错就错 | 会话2判据 + render页脚 |

# 附A · 对抗验证：两轮攻击原文

## 攻击报告 1

【怀疑者裁决】先回答总问题:这套系统的静息功耗不是零,而它假装是零。周六两小时的人,真正的敌人不是纪律松,是**每次会话的固定开销吃掉产出时间**。以下按死亡顺序排列。

**死法1 · 段0饿死:语料投喂是唯一没有扳机的环节**
全案七条不变量、两个hook、白名单断言,把每个环节都接上了机器——唯独段0"人工落料+补_frozen行"完全靠用户记得。年报季提示写在README里,而没人重读自己的README。三个月后:corpus/停在2025年报,scan跑出0新命中,页脚"数据截至日"悄悄腐烂成古董——但腐烂可见≠腐烂有人看,用户不看自己产品的页脚。系统不会报错地死,它会安静地死,这是最危险的死法,因为没有红灯。
一行修补:让 `scan.py` 每次运行第一行硬性打印"语料最新文件距今N天/宇宙内缺席年报清单",N>120天时--check黄灯——把饥饿从README搬进用户每周必看的那块屏幕。

**死法2 · 会话4横死半途:迁移量与两小时会话模型结构性冲突**
"最重一役"要求202行逐条解释、236边加5列、84条打包行标注、等级映射全量应用——这不是一个两小时会话,是四到六个。但hook要求commit前--check全绿,而迁移半成品必然不变量全红:于是半途工作要么攒在working tree里跨三个周六不落盘(断线丢工L3原样复发),要么用户第二周就学会`--no-verify`(从此hook形同虚设)。会话5"回本时刻"永远到不了,无回报期弃坑——讣告里写给A案的死因,C案自己先犯。
一行修补:会话4改为写一次性`migrate.py`脚本(跑完即删,不入白名单),人肉只审脚本diff和202行例外清单,单个周六内一次性绿灯落账。

**死法3 · 判定闸通胀:20条/会话的手速撑不起432家×词表的队列**
每条判定=开语料+核上下文+抄±40字引语+找锚URL+写triage行,乐观8-10分钟一条,两小时净判12-15条。首扫净队列大概率数百条,意味着系统头三个月每个周六全部耗在段2,"用户只审diff"退化成"用户就是判定闸",审阅环节(段4)第一个被跳过——评价闭环里唯一的人类防线失守,回到L5。同时33条ANON解匿、84条打包行展开这类"未来会话"在两小时预算下优先级永远排不上,ANON会成为永久状态而非过渡状态——诚实,但也意味着边层从此冻结在236条的质量上。
一行修补:scan输出队列按"空叶格优先+无碰撞史词降级抽检"排序,保证每个两小时会话在全景图上可见地点亮至少一个格子——用每周一次的产品级正反馈买长期坚持,这比任何纪律条文都更能防弃坑。

**附注(不算死法,算裂缝)**:triage的hit_id含引语前缀hash——换pdftotext版本或改词表,hash全变,"同一误报一生只分诊一次"的承诺静默失效,已驳回的碰撞集体还魂。修补:hit_id改为`公司+cell_id+来源文件`,把引语从身份里拿出去。

## 攻击报告 2

【怀疑者报告 · 三个最可能的死法】

**死法一 · 分母失守，死于会话4当天（L4，借不变量③自己的手）**
迁移源 panorama-data.json 202行带 market_code={A股,美股,港股,台股…}，而 corpus/_frozen 基座是432份**A股**年报——Coherent/Fabrinet/Lumentum 这批美股点（恰是236条边的证据主产地）迁入 points 的那一刻，自指不变量③"上市公司必∈_frozen"全线红灯。当天最省力的动作不是补美股10-K入语料，而是给③加豁免值——而 schema 里已有 ANON、EXT、宇宙外观察三个豁免先例，第四个豁免的心理成本≈0。豁免一开，"上市≠在分母"成常态，_frozen 退化为装饰品，L4原样复活：宇宙边界又变成没人能回答"为何是这432家"的默认值。终案会话4判据只查"202行不吞行"，恰好没查这一条。
**修补**：会话4判据加一行——美股/港股点的10-K/年报文件先入 corpus/+_frozen（版本号升v2、逐行带出处），不变量③零豁免通过；任何对不变量的放宽必须以 _frozen 版本号升级+出处行的形式留痕，禁止在 scan.py 里加 if。

**死法二 · 常识再遭误杀，死于会话5（L2，被"无空引语后门"反杀，并诱发L7）**
点准入三路径全部要求文件引语，宇宙内公司实际只剩路径①一条：语料命中。但当初光库/三环/福晶隐形的根因（A股披露语言不含扫描词、图像版PDF无文本层、产品叫"声光调制器"不叫词表里的"隔离器"）一个都没被此方案消除——scan 扫不到，判定闸就无从判，模型明知的公司在新系统里依然无合法入口（路径②只给宇宙外，官网锚对宇宙内公司非法）。会话5判据偏偏赌"光库三环福晶带引语入points"，判据兑现不了时只有两条歪路：放宽词表硬凑命中（直奔L7碰撞）或口头放松引语要求（证据纪律溃堤）。这正是L2的原始剧本：纪律没错，辖区画错。
**修补**：路径①改为"该公司**自家披露件**（年报/招股书/官网产品页）任一逐字引语+锚即可入点，不要求经词表命中"——常识公司走 triage 来源=人工 直进判定闸，词表只管发现、不管准入。

**死法三 · 治理文档在豁免区转世，慢死（L5，白名单亲手留的门）**
不变量⑥原文："archive/与refs/之外新增.md即失败"——refs/ 是白名单的法外之地，而它恰是最想写字的地方：每个解匿判例、每条路由心得、每次财年口径裁决都"理应"沉淀成参考件。六个月后 refs/ 从4件长到40件，判定闸会话开场先读半兆"参考"，token 花在读文档而非判命中——流程自嗨换了个目录名复活。第二条暗道：commit-msg 的"维护:"前缀是零diff会话的合法化图章，"整理refs""重构words注释"皆可盖章通过，产出三数形同虚设。
**修补**：refs/ 文件数封顶（≤6）计入不变量⑥，新增参考件必须在 commit-msg 引用它救下的具体 triage 驳回行；"维护:"提交每月限额1次，超限 pre-commit 拒绝。

**候补警告（L3编排复辟，一行）**：会话4"最重一役"是202行×新树叶格对齐——这正是历史上诱发十几路 subagent 并发和单位事故的工作形状；建议在会话4判据里写死"单线程、迁移脚本用完即删、任何并行=违规"，否则死法一和它会在同一天叠加引爆。

一句话总评：这份终案把闸修得很硬，但三个死法全出在**豁免值、豁免路径、豁免目录**——系统不会死于纪律太松，会死于自己合法开的口子。盯住豁免，就盯住了全部。
