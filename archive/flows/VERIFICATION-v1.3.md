## 本轮两个硬发现

**1. 对马出口按进料加工贸易申报，而非保税物流监管方式**（红队 Y1-F10/F11 修正）
数据（A级）：对马出口 70-89% 按进料加工贸易申报。2026-06 三个不同维度金额（原
误写为同一个 $222M 同额）：对马出口总额约 $260.43M，其中进料加工约 $222.30M；
江苏注册主体对马约 $221.64M——后两者数值接近但维度不同，非同额。
推断边界（修正原"真产能转移"）：进料加工只区分中国出口端监管口径，**不能判定
马来西亚接收端用途或实质加工深度**（自有产能/第三方封测/再出口/集团内调拨均不可
排除，海关数据无企业与收货人）。与判例#002 PINEWAVE 的关系仅为方向相容：主体、
期间、对手方均未对齐，构成 C 级一致性假设（原"判例#005 素材/闭环"降级，见判例库），
成立需旭创马来实体或报关主体侧独立证据。

**2. 注册地×去向：省级注册地快照差异**（X1，代理推断C级；红队 Y1-F12 修正）
2026-06 单月快照：四川注册主体对泰国约 $50.5M、对美国约 $24.8M、对马来西亚约
$0.57M（非绝对零）；湖北注册主体三向较均衡。**将四川/江苏/湖北代理为特定公司仅为
C 级假设**（各省均有其他光通信/器件/贸易主体，注册地与生产地可分离），不可表述为
公司级去向；且为单月数据，不外推。linkage 红线据此修订（允许注册地代理、强制 C 级标注）。
