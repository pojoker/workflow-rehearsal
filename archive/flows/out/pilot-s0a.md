# S0a 三窄词公告扫描试点 [Q1]

检索日：2026-07-24  
词表：`flows/BOM-词表-v0.md`  
三窄词：InP衬底（含“磷化铟衬底”）、三甲基铟、AWG（含“阵列波导光栅”）  
基线：`output/nodes.csv`（169 个节点，文件 170 行含表头）  
上限：100 份去重文档或 4 人时等效；噪声率 >90% 或连续 2 人时零新增合格关系即停。

> 本文所有六类标签均为**发现队列候选标注**，不是判定闸终裁；终裁 owner 仍为终验。
> 本试点未改 `output/nodes.csv`、`output/edges.csv`，也未生成任何合格关系边。

## 1. 执行结论

- 等效公告检索通道 Wind `financial_docs.get_company_announcements` 可访问，但不是可复算的严格全文检索：
  `top_k=100` 实际每次仅返回约 8—16 条、没有分页游标/稳定文档 ID/总库命中数，
  同参重复调用的文档集合会漂移。
- 冻结的主漏斗由一轮“组合写法”3 query 和一轮“同义写法拆分”5 query 构成：
  **74 个返回位次 → 59 份去重文档 → 15 生产中 / 5 拟生产 / 2 采购使用 /
  0 销售代理 / 4 仅提及 / 33 无法判断**。
- 以“不能产生生产中/拟生产候选”的文档为噪声，整体噪声率为
  **39/59 = 66.1%**。
- AWG 子项为 **28/31 = 90.3%** 噪声，超过预登记淘汰线；原因是 `AWG`
  被召回为合景泰富英文字符噪声，“阵列波导光栅”被召回为证券简称“波导”。
  **AWG 子项当场停止，不再扩词或追加抽样。**
- InP 子项有净新增生产候选；三甲基铟与 AWG 的生产候选均已存在于
  `nodes.csv`（南大光电、仕佳光子），没有带来净新增主体。
- 试点有正的候选产出，但接口契约未达到“全库有界扫描”要求。建议把当前 Wind
  路径保留为候选信源；S0a 正式入流程前，需 exact phrase、稳定 doc_id/URL、分页和
  总命中数。

## 2. 口径

### 2.1 文档主分类

每份去重文档只进入一个主分类；同一文档同时包含多个主体/状态时，按对目标部件最直接、
证据最强的状态归类，并在备注中保留次级状态。

| 分类 | 本试点候选口径 |
|---|---|
| 生产中 | 文档明确显示某具名主体正在生产、销售、批量交付或有现行供货合同 |
| 拟生产 | 募投、扩产、收购接续或拟设项目，尚有审批、建设、交割或验证条件 |
| 采购使用 | 文档明确显示目标部件/对应产线为其采购或工艺使用对象 |
| 销售代理 | 仅代理、经销目标部件，未证明自身生产 |
| 仅提及 | 有逐字词或邻层产品，但不能支持上述四类；包括 epiwafer 与 substrate 层级错位 |
| 无法判断 | 语义召回但未见逐字命中，或返回片段不足以判断 |

### 2.2 噪声率

本试点目标是发现生产主体，因此：

`噪声 = 采购使用 + 销售代理 + 仅提及 + 无法判断`

拟生产保留为有效候选，不计噪声；是否最终入账由判定闸 owner 决定。

### 2.3 去重

Wind 不返回 URL/doc_id，故按“标准化标题 + 披露日期”去重；标题相同但日期不同的公告保留。
同一公告在不同词或不同 query 中重复出现只计一次。该方法无法识别标题/date 相同但版本不同的
修订件，是本次已知盲点。

不同词之间有 2 份兴业科技公告重叠，因此各词去重数之和 61，大于全局去重数 59。

| 词组 | 去重文档 | 生产中 | 拟生产 | 采购使用 | 销售代理 | 仅提及 | 无法判断 | 噪声率 |

| InP衬底 / 磷化铟衬底 | 18 | 9 | 3 | 2 | 0 | 2 | 2 | 33.3% |
