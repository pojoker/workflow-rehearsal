# flows/ROADMAP-v1.7.md — 主流程修订案 v1.7（负空间审计七项并入）

**状态：未冻结草案（2026-07-24）。** 来源：用户分支会话（只读）产出，主会话落盘。
冻结前置条件：①v1.6 收口完成；②本案经 codex 对抗评审通过。评审前引用须注明
"未冻结草案"。

**触发背景**：用户提问"用部件关键词搜年报是否更快发现上下游"暴露一类盲点——
项目把"从已知公司出发"当成唯一搜索算子，红队从来只审产出物、从未审搜索空间。
负空间盘点得出七项修订（A-G）。

## A. 流程结构：从五段变七段

```
S0  节点发现层（新增）
    S0a 部件词表扫描：BOM词表(从台账证据长出,带出处) → 巨潮全文检索全库 → 命中池
    S0b 对手方递归跳：台账新增节点中凡自身为上市/挂牌主体(A股/科创/北交所/
        新三板/港美股) → 自动列入下一轮抽取队列（BFS一跳,队列深度默认1,防爆炸）
    S0c 结构性必然边清单：按BOM逐部件问"此边在台账里吗" → 缺失项=定向搜索任务
S0.5 判定闸（人工）：生产vs提及（主营/募投段命中=生产候选；行业综述/竞对/
     风险段命中=噪声）；逐条留痕；剔除显式登记
S1-S4 现有边工序不变（下载→抽取→四件套准入→分级入账）
S5  双侧对账/时间轴/图谱（现有）
S6  回测/监测（现有）
```

三条纪律：①词表有出处（猎奇BOM/源杰仕佳供应商表部件列，不从研报抄）；
②候选池只是待办清单，任何公司不经边工序不入图；③判定闸裁决逐条留痕。
S0 只改变覆盖广度，不动准入标准——与机器层"筛查不承重"同一治理逻辑。

## B. 信源清单扩充（四项新 T1 信源）

| 新信源 | 产出物类型 | 首轮试点对象 |
|---|---|---|
| 债券募集说明书/评级报告 | 实名客户/供应商表 | 华工科技、长飞（已知发债主体） |
| 裁判文书网（买卖合同纠纷） | 双方实名+金额+履约细节 | 台账161节点名称逐一检索 |
| 专利共同申请/转让（国知局） | **新边类型：研发边/技术流向边**（与供货边分层不混计） | 旭创/天孚/源杰 |
| 环评/能评公示 | 产能与设备清单 | 维持事件触发，并入 S0c 定向搜索 |

## C. 关系类型修订（修复 v1.6 误伤）

- 新增边类型：**股权边**（如旭创间接持股源杰≥5%，v1.6 已抽到但被"非供货方向"
  规则裁掉，回收入账）与**担保边**——独立分层，不参与供货集中度统计，图谱
  单独图例。
- v1.6 裁剪清单（v16-cuts.txt）按新规则复审，凡股权/担保行重新准入对应层。

## D. 完成判据（新增硬指标）

- **查全率** = 台账覆盖的部件X生产商数 / S0a全库命中且过判定闸的生产商总数，
  按层报告。
- 结构报告自此必须带查全率表；**无分母的"补全"表述禁用**。

## E. 实体归并契约（还债）

- 建 `flows/entity-registry.md`：每个节点标注法人/集团两级；归并裁决三选一
  （集团口径合并/母子分列/按披露口径照录）逐条登记理由。
- 首批处理：海信集团vs海信宽带、旭创系、长飞系、昱升两名、顺丰两名。
- 时间轴别名表与节点表统一引用该登记册，消除双标。

## F. 红队常设工位（meta 教训固化）

红队清单新增**负空间审计**，每轮固定回答三问：
①搜索算子清单相对问题定义完备吗；②信源类型清单有无新增可用而未用；
③本轮被规则裁剪的类别里有没有真结构。
产出与措辞审计同格式，**缺席视为评审未完成**。
