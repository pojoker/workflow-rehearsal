## 立项（1 项）

### T1 · 数据源通道卡（文档，非代码）
- **形态**：SOP 附录级的一页文档，已随蒸馏落入 SOP.md S1.1/S2.1/S2.4——每数据源
  一行：{UA 要求, API 端点与参数格式, 承载域名, 限速, 已知坑}。
- **依据**：摩擦类 3 次/10 检索浪费；写文档成本≈0，且彩排日志里参数已全部实测。
- **显式不做**：取数封装脚本/爬虫。理由：通道卡若能把试错归零（复跑验证），
  代码封装就是过早优化；若复跑仍出现试错，再凭新日志升级为代码立项。
