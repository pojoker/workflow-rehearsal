# REHEARSAL-P2-SUPPLEMENT.md — 国内边生产线补充（P2执行前读）

背景：seed 结论"美股先行"解决了美股侧与跨境边，但国内公司间的边缺
10-K式机制。本补充定义国内边的五条生产线。**A股是事件驱动实名**（IPO/
发债/评级时点名，年报匿名），据此调整 P2 动作。

## P2 动作修订

原 P2 的 (a)(b)(c) 保留，追加：

(d) **IPO生态反照**：对每个已入图的国内节点，检索"谁的招股书/问询回复
实名提到了它"（探针：节点名+招股书/前五大客户/前五大供应商）。注意A股
招股书**双向实名**（客户+供应商都点名）。命中即入边，边等级=实边，
必须记录**实名时点**（招股书报告期），非当期数据。

(e) **债券文件族**（新信源类，此前未登记）：对发过债/可转债的节点
（中际旭创、新易盛、天孚已知有转债史），检索其募集说明书与最近一期
**跟踪评级报告**（中诚信/联合资信等，交易所债券信息平台公开），提取
实名客户/供应商段落。⚠️ 首个动作是探针实测：评级报告实名率是未验证
的经验判断，先拉一份看实名情况再决定投入，实测结果记入日志与
anomalies.md（无论结果如何都是信源普查的增量）。

(f) **新三板/北交所配套层**（时间允许则做）：对图中出现的非上市小供应商
名，检查是否新三板挂牌/曾挂牌，其年报客户段实名率高于主板（逐年收紧，
需实测）。本项预算≤5次检索，超出即记摩擦跳过。

## 边 schema 追加字段

edges.csv 增加两列：
- `实名时点`：证据文件的报告期（非发布日）
- `鲜度状态`：当期（≤1年）/ 陈化（1-3年，连续性推断有效）/
  过期（>3年，仅作历史边，不进当前结构图主视图）

产出文档中，陈化与过期边必须与当期边视觉区分。把鲜度诚实画出来是本图
与市面产业链图的核心区别之一，不是缺陷。

## 停机纪律不变

本补充不增加总检索预算（仍100次）。(d)(e)(f) 与原动作共享 P2 预算，
优先级 (a)=(d) > (e) > (b)(c) > (f)。
