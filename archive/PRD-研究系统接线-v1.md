# PRD v1：个人研究系统"接线"计划（红队修订版）

日期：2026-07-24 ｜ 状态：依 PRD-接线-review-codex.md（29 发现）全盘修订，待复审
｜ v0 保留不改（版本纪律）

## 修订总述

v0 的四方向被红队裁定"只有方向三的业务需要有既有证据；方向四核心主张不成立"。
v1 的结构性变化：**加 Gate 0 对照组；删统一契约先行；砍方向四；三个成功判据
全部重写为不可被事后解释救活的形式**。

## 主张-证据状态表（F29 修复：本 PRD 每个承重主张的证据状态）

| 主张 | 本地出处 | 状态 |
|---|---|---|
| 证据纪律有防御价值 | 彩排红队记录（A级降级/全称化拦截/匿名串接拦截） | **单域已证**（仅供应链图谱域，不外推） |

## Gate 0：手工基线（新增，正式候选终态）

维持现状（分支 F 月度留痕 + R5/R7 事件触发 + 手动调用各 skill），在**一个完整
海关发布周期**（2026-08-15 ~ 09-15）内如实记录：

```
{应处理事件, 发现方式, 发现时间, 是否漏掉, 人工分钟数, 是否产生有效更新}
```

- 所有后续 MVP 与此基线同口径比较；
- **停止门**：若某方向相对基线只省几分钟但增加持续维护，该方向判"维持手工即
  合格终态"并关闭——这是正常结局，不是失败。

## 契约策略（F03/F26 修复：从"先建"改为"后蒸馏"）

不预先建统一 claim 契约。各窄流程先用**最小事件记录 + 稳定文件引用**跑；当
**≥2 个流程在真实运行中出现同一字段/状态摩擦**时，才启动契约蒸馏，且必须实现
红队指定的分离结构：

- `claims.jsonl`（不可变主张：id/created_at/as_of/author/scope/原文/类型/
  source_locator/version_hash/evidence_refs）与 `claim-events.jsonl`
  （created/triggered/verified/falsified/expired/corrected 事件，含
  supersedes/reason）分表；当前状态是可重建视图；
- 证据字段三维分离：source_tier / verification_verdict / domain_grade——
  **禁止跨域复用字母等级**（解匿的 A/B/C 不得借给预测假设）；
- 事实/逻辑/预测/配置四类主张各用类型特定 schema，不强迫全部带阈值（防伪精确）；
- 最小责任环：`候选生成(模型) → schema 校验 → 用户批准/驳回 → 追加事件 →
  视图重建`；未经批准的模型输出停在 proposed，**永不直接改事实台账**。
- 纠错模型（F08/F24）：原始记录不可静默改写；纠错=追加 amendment 事件（保留
  原文/原因/是否已见结果）；派生视图可重建覆盖。

## 方向三：披露事件哨兵（唯一首批实现，shadow 模式）

**范围收缩**：只做海关一个事件源；**shadow 模式**——哨兵只做检测和生成候选
工单，**不自动更新任何台账**，与手工基线并行运行。

- 事件状态机（F21）：`expected → detected → deduplicated(按文件hash) →
  reviewed(人工) → applied / no-op / corrected / failed`；漏报与失败计入分母。
- 通道状态如实拆列（F18）：海关={原始来源可达✓, 发布检测未运行, 工单生成
  未运行, 增量更新未运行, 价值未验证}——只有第一列有执行记录。
- **成功判据（F20 修复，内部 SLA 制）**：一个发布周期内，
  `官方发布→检测→工单→人工确认→台账新版本` 五时间戳齐全、在事前约定时限
  （检测≤24h、工单≤48h）内完成、影响对象抽检正确、**零未经批准的事实变更**，
  且相对 Gate 0 基线漏报更少或分钟数更低。外部时间差仅可对**事前冻结的有限
  媒体清单**做描述性旁证，禁止"早于任一"表述。
- 失败处置：SLA 不达或无增量 → 停在手工态（Gate 0 即终态），哨兵代码归档。

## 方向二：单源预注册登记簿（条件启动）

**启动条件**：方向三或其他真实流程暴露出跨 skill 登记摩擦之后，不提前启动。

- **单源**：先接 spread-macro-watch（结构最接近"论点→观察变量"）；第二源是
  独立的通用性试验，不属于本 MVP。
- **只登记决策承重 claim**（F14）：会改变监测/配置/退出条件的判断才入账；
  其他输出保留原文引用，不强制降解。所有阈值带 `{依据, 选定时已见信息,
  适用范围}`，无依据标"约定"（承回测协议污点登记框架）。
- **成功判据（F16 修复，三门分立）**：
  1. `schema_valid / admitted = 100%`（准入即完整，不允许 80% 式豁免）；
  2. `registered / eligible_candidate_judgments` 全量报告，候选分母在看到
     结果前冻结（该源一次完整运行的全部输出为分母）；
  3. 全程人工分钟数与放弃原因表。
- 危险模式红线（F17）：去重不吞冲突；数据源失效 = unknown 而非安全/触发；
  触发只生成待审工单；旧版本 skill 输出不覆盖新版本；设告警预算与熔断。

## 方向一：叙事-披露缺口审计（一次性手工试验）

**范围收缩**：不自动附着到每次扫描。一次性试验：取**一份已冻结的**光模块
扫描输出，事前列出其中 3-5 条承重叙事，手工走溯源+台账，产出缺口清单。

- **成功判据（F12 修复，操作性门,不用未来反转）**：每条叙事的
  `{核验成本分钟数, 血缘完整性, 公开不可验证比例}` 全量报告，且清单**改变了
  至少一项后续核查优先级**（有无缺口清单时的核查顺序差异，事前记录）。
  "缺口是否富集后续修正"降级为独立前瞻研究（须冻结全样本+对照组+判定窗口+
  四态全量报告），不作本试验验收。
- 红线（F13）：公开缺失≠证伪；转载链按同一源计数；叙事集合核验前冻结；
  清单只供核查排序，不生成公司质量/交易结论，不对外发布；付费墙标不可验证
  不绕行。
- 第二行业试验 = 独立的外部有效性试验，另立工单。

## 方向四：砍掉（F22 采纳）

从实现路线**删除**。理由照录红队：观察性分桶在任何样本量下都不能回答"系统
让判断变好"（使用 skill 非随机分配，选择偏差无解）。

- 可保留：一个轻量决策日志（纯个人复盘，自由格式），**不得命名为系统效果
  试验、不得分桶归因、不得评价 skill/操作者能力**。
- 重开条件：出现自然积累的、完整捕获的可比样本 + 独立的识别设计，届时另立
  PRD 走独立评审。

## 执行序（红队修正版，照录）

```
1. Gate 0 手工基线（2026-08-15 起一个海关发布周期）—— 正式候选终态
2. 方向三 shadow MVP（与基线并行,只检测不写台账）
3. 方向二 单源 MVP（仅当真实摩擦已暴露）
4. 方向一 一次性手工试验（独立,可与2并行）
5. 方向四 已砍
契约蒸馏：悬置,触发条件=≥2流程出现同一摩擦
```

## 全局红线（F28 补全）

1. 禁止自动交易/调仓——任何触发只产生待审工单；
2. 模型未经用户批准不得修改事实台账/判例/冻结文件；
3. 公开不可验证 ≠ 证伪，二者永远分列；
4. 付费墙/授权内容：标不可验证，不绕行，不转存无权保存的全文；
5. 来源更正必须传播到引用处（hash 追踪）；
6. 转载/循环来源不得当独立证据计数；
7. 分母、样本集、判据一律在见结果前冻结，事后改动=协议偏离；
8. 缺失数据 = unknown，不默认安全也不默认触发；
9. 不自动对外发布任何可能构成指控的表述；
10. 本 PRD 首轮只检验可审计性、漏触发、延迟与人工成本；决策价值与 alpha
    不在可证范围，任何相关表述按未证假设处理。

## 失败处置预注册

每个方向的停止门写在各节内；总停止门：若 Gate 0 显示现状漏触发率与成本已可
接受，**整个接线计划关闭，维持手工态**——这是合格结局，记录后不追加沉没成本。
