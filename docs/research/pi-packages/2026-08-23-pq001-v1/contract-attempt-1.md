# PQ001 Pi 研究合同 v1：attempt-1（历史输入）

状态：`draft_only`
目标问题：`PQ001 光模块在系统中解决什么问题，边界在哪里？`
本轮阶段：受控研究，不写事实账本，不改变问题覆盖状态

## 1. 本轮答案边界

### 可以回答

1. 光模块在主机电系统与外部光链路之间承担的系统级功能；
2. 以 OSFP 可插拔模块为明确样本时，主机电侧、模块本体、外部光侧、管理接口和机械/热界面
   分别在哪里；
3. 哪些结论是 OSFP/可插拔形态特有，不能推广为所有光模块的共同边界。

### 只读上下文

- `RQ000`：上游对象口径，不允许重新回答；
- `PQ002`：下游功能链，不允许展开组件内部工作原理；
- `PQ003`：下游参考样机选择，只允许生成有证据触发的研究注记，不允许替它选型。

### 禁止

- 回答具体组件 BOM、制造工艺、设备、技术路线、WHY、公司能力群、供货或投资问题；
- 把 OSFP 的机械/电/热边界推广成所有光模块的共同边界；
- 把 cage、host PCB 或 host-side riding heatsink 无条件写成模块本体组成；
- 把 form-factor MSA 的范围写成完整光学信号标准；
- 新增 CQ/PQ/TQ/WQ 编号；
- 输出 append-ready YAML，或声称 PQ001 已覆盖；
- 生成“本轮未研究某问题”类行政注记；
- 联网、运行工具、shell、Python、校验命令或写文件。

## 2. 体系与主张类型

- 所有原子草案 `system` 固定为 `物理知识`；
- `question_id` 固定为 `PQ001`；
- `claim_type` 只允许：`公司口径`、`OSFP形态规范事实`、`组织官方口径`；
- 公司口径只能证明发布主体自身的功能/构成表述；
- OSFP 规范事实只能描述 OSFP/OSFP-RHS；
- OIF 官方页面只能证明其对 CMIS 适用对象和 host-to-module 管理通信的官方说明，不能替代 CMIS
  规范正文。

## 3. 证据纪律

- 只允许使用 `sources.md` 中标为 `admissible_for_draft: true` 的来源；
- 必须先按来源给出的完整上下文理解，再提出缺口，不能用短引人为制造矛盾；
- 同一主张可以有多个证据，但不得把不同发布主体的句子焊成一个无主体的行业事实；
- 每条结论必须写适用边界和反向禁止推论；
- 所有草案 `would_mark_covered` 固定为 `false`。

## 4. 输出格式

1. `PQ001 范围声明`：不超过 180 字，必须明确“本轮以 OSFP 可插拔模块观察边界，不代表全部
   光模块形态”；
2. `系统边界表`：至少包含：
   - 系统级问题；
   - 主机高速电信号边界；
   - 供电与低速管理边界；
   - 机械/热边界；
   - 外部光接口边界；
   - OSFP 样本的适用限制；
3. `原子主张草案`：最多 5 条，每条含：
   - `draft_id`
   - `system`
   - `question_id`
   - `claim_type`
   - `statement`
   - `evidence_ids`
   - `boundary`
   - `rejected_inference`
   - `would_mark_covered`（固定 false）
4. `研究注记`：0–3 条，只能挂 `PQ001` 或 `PQ003`，每条含：
   - `attach_to`
   - `note`
   - `trigger_evidence_ids`
   - `why_existing_question_can_hold_it`
   - `expected_answer_shape`
   - `next_action`
   - `stop_condition`
5. `拒绝的推论`：至少覆盖“OSFP=所有光模块”“cage/host heatsink=模块本体”“form-factor
   MSA=完整光学标准”三类；
6. `自检矩阵`：逐项检查体系、QID、锚型、适用边界、上下文、注记必要性、覆盖状态；
7. `停止结论`：注记的停止条件是局部条件，不得把它们写成开启其他 draft-only 轮次的全局门闩。

## 5. 注记必要性

研究注记必须同时满足：

1. 由具体证据触发；
2. 指向 PQ001 或 PQ003 尚未解决的实质矛盾/资料缺口；
3. 给出可执行下一步；
4. 有可判定停止条件；
5. 解释为什么挂在该层级，而不是相邻问题。

不满足五项时不输出；少于 3 条是正常结果。
