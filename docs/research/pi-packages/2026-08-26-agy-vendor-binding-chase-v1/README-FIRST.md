# README FIRST

本包测试 AGY（Gemini 3.7 Flash）能否找到“公司—精确产品/产品族—硅光路线”的一手绑定，并把展示、公开列品、量产和客户服务严格分开。

当前结论：

- 中际旭创：产品族级硅光展示证据；
- 新易盛：产品族级 200G/lane LPO SiPh 展示证据；
- 芯速联：两个精确型号的官方硅光 LPO DR8 产品页；
- 三者都没有在本轮形成可写入知识库的 confirmed company service group。

阅读顺序：

1. `shared-contract.md`
2. `source-excerpts.md`
3. `adjudication.md`
4. `pi-handoff.md`
5. `pi-output.md`（Pi 完成后）
