# Pi 指令

只读取本包 `pi-handoff.md`。不要读取 AGY 原始输出，不要自行联网，不要调用工具。

严格输出四部分：

1. `公司—路线观察卡`：每家公司逐条列 observation id、精确 evidence subject、可确认轴值、成熟度、UNKNOWN 和证据 URL。
2. `TQ009→TQ013 挂载建议`：判断是否复用 `route_service_evidence` 并增加 evidence_stage；不得创建正式公司群或正式 Route Profile。
3. `双体系 + WHY 差距表`：物理体系、路线体系、WHY 桥分别说明本轮新增了什么、仍缺什么。
4. `下一轮单一最小闭环`：只选择一个产品族，生成 5–8 条研究问题，按“上游约束 → 路线选择 → 条件化优势/代价 → 下游物理变化 → 公司角色证据”排序；每条映射现有 QID，标注重复/细化；不得回答这些问题。

禁止：补全 UNKNOWN、跨产品拼接、路线排名、营销主张晋升、客户/出货推断、WHY 写入、知识库写入、coverage 变化、新 QID。
