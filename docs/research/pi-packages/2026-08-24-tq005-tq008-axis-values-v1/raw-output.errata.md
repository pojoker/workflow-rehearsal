# Pi raw 输出勘误

`raw-output.md` 是不可变审计原文。以下句子不得继续消费：

1. 所有把 `GaAs` 写成本轮已证实 platform/material 值的句子；当前没有冻结来源支持。
2. TQ007 integration 表中把 `pluggable / on-board / co-packaged` 当作光子集成值的句子；它们属于 TQ008。
3. “EML 当前只有一个一手定义来源”的开放问题；S11 与 S12 已形成两个公司官方定义来源。
4. 所有把 S9 的 `3 nm DSP` 变体直接标成 `full-retimed` 或明确 Rx retimed 的句子；原文未披露该方向职责。
5. 所有把 100G-DR-LPO profile 的 host FEC/retiming/DAC/ADC 职责推广为 generic linear 全称定义的句子。
6. 所有把 LRO、RTLR、half-retimed 直接当完全同义词的句子。
7. 所有断言 Intel stand-alone on-board 必然不位于某类 substrate 的句子；其精确位置尚未披露。

后续唯一有效文本为 `post-adjudication-effective-text.md`。
