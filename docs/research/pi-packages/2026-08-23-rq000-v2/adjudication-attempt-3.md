## 2. 剩余内容问题

### A5：注记 3 是为了填满配额生成的无效注记

`PQ002` 注记没有由“关于 PQ002 的新证据矛盾或缺口”触发，只是在记录“本轮未研究 PQ002”。
S1–S3 也不能作为这条行政性注记的触发证据。把未触碰的每个下游问题都写成注记，会重新造成
问题树/研究队列膨胀，只是从新增节点换成了新增注记。

裁决：删除注记 3。研究注记是“最多 3 条”，不是必须凑满 3 条；没有证据触发的可执行缺口时不
输出注记。

### A6：自检只检查格式，没有检查注记必要性

自检矩阵与正文在机械规则上相符，但未检查每条注记是否有独立证据触发、是否会解锁后续动作。

裁决：下一版合同增加“注记必要性”检查，明确禁止“本轮未研究/未触碰”类行政注记。
