# RQ000 口径声明

RQ000（什么是光模块）本轮仅能给出分层口径：公司口径将光模块描述为执行光电转换、由光电子器件与功能电路等组成的部件，光学元件供应商另强调光学与光纤器件封装；MSA 页面只反映特定形态规范覆盖范围。尚无跨来源的唯一标准定义，也不含技术路线内容。

# 拒绝的推论

1. **从 S1–S3 推出“行业唯一标准定义”或“所有光模块都如此”**：S1–S3 均为公司定期报告口径，只能证明各公司如何定义或描述对象，证据类型不支持唯一标准定义。
2. **从 S4 推出“所有光模块都采用 OSFP”或“OSFP 即行业通用形态”**：S4 只覆盖 OSFP/OSFP-XD 形态规范范围，不覆盖其他 MSA，更不能代表全行业。
3. **从 S5 推出“2 米是铜的物理极限”“超过 2 米只能用光”或“某 PMD 已获批准/已商业采用”**：S5 只是 IEEE 802.3 工作组批准的项目目标，不是完整已批准标准正文，项目目标不等于物理极限或已批准产品事实。
4. **从 S2 与 S3 拼出“光模块的完整、唯一构成”**：S2 说“光电子器件和功能电路等组成”，S3 说“由光学元组件、光纤器件封装而成”，两者角度不同且均含非穷尽表述，不能推出完整 BOM 或所有实现均采用同一构成。
5. **从 S3 推出“光模块只有光学元件、不含电路或结构件”**：S3 是光学元件供应商的口径，只描述其视角下的光学构成。
6. **从 S1 推出“光模块只有光电转换这一个功能”**：S1 只给出作用口径，未否定其他功能。
7. **从 S1–S5 任何组合推出技术路线 KN、WHY、公司能力群、供货或投资结论**：合同明确禁止，且证据类型（公司口径/页面/项目目标）不支持此类推断。
