# TQ004 draft-only 研究合同

## 1. 唯一目标

回答现有问题：`TQ004 比较路线时必须分开哪些正交选择轴？`

本轮只建立“路线轴字典”和“可比较规则”，不回答路线胜负、公司归群、市场份额，也不构造完整
路线画像。所有内容 draft-only，不写 canonical，不改变 TQ004 覆盖状态，不生成新问题 ID。

## 2. 核心判断规则

“技术路线”必须写成多个轴值的组合，至少分开：

1. `TQ005` 产品/链路标准轴：速率、lane/波长组织、介质、PMD、reach 等互操作边界；
2. `TQ006` 电接口架构轴：DSP/retiming/linear equalization 等信号处理放在哪里；
3. `TQ007` 光子平台轴：怎样产生、调制、传输和探测光，EML/SiPh/VCSEL 等属于何种层级；
4. `TQ008` 封装架构轴：pluggable、on-board/NPO、CPO 等决定光学相对 ASIC 的位置与可维护边界。

“正交”只表示分析时必须分别回答，不表示所有轴值能任意组合、没有工程耦合。

## 3. 验收条件

1. 每个轴必须写清：它回答的问题、典型轴值、可观察字段、不能回答什么。
2. 至少给出两组一手来源支持的“相同某轴、其他轴不同”或“同一技术可跨不同轴组合”的实例。
3. 必须解释为什么 `EML/SiPh`、`DSP/LPO`、`pluggable/CPO` 不能放在同一维度横向排名。
4. 必须区分：标准/规范定义、公司单产品或演示、分析抽象、受限推论。
5. 研究缺口只能挂现有 `TQ005`–`TQ009`、`PQ010`、`WQ002`、`WQ003`；不得创造新 QID。
6. 所有原子主张有唯一 `draft_id`，并写 `would_mark_covered: false`。

## 4. 禁止推论

- 不得声称 EML、SiPh、LPO、CPO 互为完整替代路线；
- 不得由“可组合”推成所有组合均可量产或经济可行；
- 不得把同一家公司演示多个方案写成市场主流或份额；
- 不得从轴定义直接推出受益公司；
- 不得把 OIF framework、MSA specification、产品演示与 IEEE final standard 混成同一证据层。

## 5. 输出格式

只输出中文 Markdown，包含：结论摘要、路线轴字典、术语归轴表、跨轴组合实例、原子主张、
研究注记、拒绝推论、自检矩阵、停止结论。
