# ADR-0010：开格标准——什么时候给产业结构树开一个新格子

- 状态：accepted（2026-08-23，用户确认）
- 背景：2026-08-21 日更判定闸遇到"紫光国微高基频差分晶振量产自述但树无格"，暴露出开格没有成文标准；同日赛微 MEMS-OCS（树外）、矽电探针台（EQ7 扩界）两个对照案在手，构成完整的判例集。

## 标准：四条全过才开格

1. **BOM 真实性**——必须是光模块的物理组成，或制造光模块的必经工序（设备轴 EQ）。检验：能指出它在模块里/工序里的物理位置。市场分类不算数。
2. **不可归约**——现有格子扩界后仍装不下，才开新格。
3. **证据可得**——宇宙内至少一家有披露级证据；或者是"有证据的空"，空格必须带检索记录（关键词/范围/日期/命中数，KN004 模式），证明"找过没有"而非"没找过"。
4. **边界可写**——一句话写得清什么进、什么不进，未来候选可机械判定。写不出边界说明还没理解这个环节，不开。

判定顺序：在模块里吗？→ 现有格装得下吗？→ 有证据吗？→ 边界写得清吗？
卡在第 1 句 → 树外；卡在第 2 句 → 扩界；卡在第 3 句 → 待判挂监视；卡在第 4 句 → 先搞懂环节。

## 判例

| 案 | 结果 | 卡位 |
|---|---|---|
| 先导基电 Micro-TEC（2026-07-30） | 开 D13 温控元件 | 四条全过（TEC 是 TOSA/光引擎物理组成，既有格无温控） |
| 矽电探针台（2026-08-23） | 不开格，EQ7 名称扩界含探针台/分选 | 第 2 条：与测试仪器同属"测试"语义，扩界即收（P171） |
| 紫光国微差分晶振（2026-08-23） | 开 C7 时钟/频控器件（P274） | 四条全过：在模块里（DSP/SerDes 参考时钟，贴模块 PCB）；C5"电芯片"装不下（频控器件物理上不是芯片，产业生态也不同源）；有 2026-08-19 投关表量产自述；边界可写（差分晶振/温补/时钟发生器/缓冲器） |
| 赛微 MEMS-OCS（2026-08-23） | 不开格，树外 | 第 1 条：OCS 是独立光交换网元（光进光出不变电），是光模块的下游邻居，不在模块 BOM 内（P199 注记） |

## 附则

- 开格即流向：新格必须同时声明 flows（C7 → MOD1/MOD2/MOD3）。
- 空格是合法状态（"有证据的空"），不为了消灭空格而开格。
- 本标准是判定闸纪律，后续由判定闸会话引用；与 knowledge.yaml 的行业知识分工：那里回答"环节为什么难"，本件回答"什么时候有新环节"。
