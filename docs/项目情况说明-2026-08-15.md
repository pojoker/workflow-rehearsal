# 光模块产业链数据项目 · 情况说明（2026-08-15）

> 对外说明稿。回答三个问题：这套数据是什么、为什么可信、现在有什么。
> 仓库：`workflow-rehearsal`，分支 `codex/industry-chain-v2`（已全部推送 GitHub）。

## 1. 这是什么

一套**以一手披露为唯一证据来源**的光模块产业链数据库，回答四类问题：

1. 产业由哪些环节组成（结构树）
2. 谁具备做各环节的能力、证据是什么（参与识别）
3. 各环节/各公司真实出货量是多少（出货量层）
4. 宏观与地缘变量怎么影响链条（海关流向/FCC 情景/海外事件雷达）

**明确不做的**：不回答"A 是不是 B 的供应商"（无双边实证不立边）；不做投资价值判断；推断数据永不进 A/B 级；未落地政策（如 FCC 草案）永不进基准表。

## 2. 方法逻辑（为什么可信）

### 2.1 结构先行，公司靠证据挂靠

先独立定义产业骨架 `tree.yaml`——40 格 BOM 树（衬底/外延/光芯片/器件/模块/PCB/结构件/设备/材料），再按**公司自家披露自述 + 可点开锚**把公司挂到格子上。没有自述证据的能力不登记；空格显式保留为"研究缺口"而非留白。

### 2.2 证据五件与四级分级

每个点位带：命中引语（原文子串可机检）、锚点 URL、状态（生产中/在建）、判定注记（为什么这么判）、检索日期。证据分级：**A** 双边/官方实证、**B** 单一硬证据（年报产销表等量齐露直接披露）、**C** 推断、**D** 情景。出货量层规则更严：推断行封顶 C，B 仅直接披露，禁 A。

### 2.3 判定闸：起草与复核分离

子代理（pi/codebuddy 等）起草 → 闸主机械复核：引语子串验证、数字重算、**回原文表区逐列对位**（PDF 抽取横表错位是结构性风险，已四次拦截此类错误）→ `scan.py --check` 十二项不变量全绿 → 按固定格式提交（每条 commit 带产出计数：+N 点 +M 边 空格 A/B 驳回 K）。

### 2.4 双代理交叉验收

kimi（闸主/落库）× codex（独立验收）通过协作账本（`refs/CODEX-KIMI-COLLAB.md`，单写者令牌制）交互。验收是真打回：单位换算差 1000 倍、收入/销量口径不匹配、上年列转置等均被抓出返修，四批出货量数据全部经 codex 终审 accepted 才闭环。

### 2.5 日更与校准

- 每日 06:47 自动跑增量：投关表/互动易/公告流三车道 + 召回队列差分 + 一页日报；无实质增量免开闸。
- 半年报季全量校准；海关月度序列更新后出货量上限检重跑。
- 每条驳回留痕于 `triage.csv`（含可重启条件），目前 560 条判定轨迹：已入点 135、驳回 398、待判 27。

## 4. 分析维度

- **产业链**：40 格六层（材料→衬底→外延→芯片→器件→模块→设备/板材/结构件）
- **技术路线**：数通直检（800G/1.6T）/相干（400ZR+）/电信接入/CPO 硅光
- **状态**：生产中 / 在建（送样、验证、导入期）/ 待判（带重启条件）/ 空格（显式研究缺口）
- **证据等级**：B 直接披露 / C 推断 / D 情景
- **时间**：2025 年报季基线 + 日更增量 + 半年报校准窗口
- **地域**：A 股全宇宙 + 港股/美股/北交所/IPO 在审 + 海关流向（出口目的国结构）

## 5. 质量控制

- `scan.py` 十二项不变量每次提交强制全绿（引语可回溯、ID 唯一、等级合法、单位枚举、锚文件存在等），git 钩子拦截，从未用 `--no-verify`。
- 多代理验收循环 10 轮无放水记录（打回 4 次全部返修闭环）。
- 信源分层纪律：年报/问询函 > 投关表 > 互动易 > 媒体线索（线索须 T1 对读后才收）。问询函回复已被验证为高产信源（比年报披露粒度更细）。

## 7. 怎么用

数据只有一份（csv/yaml），所有 md/html 都是渲染产物。核心入口：

- `points.csv` / `edges.csv`：谁参与、参与什么环节、证据原文
- `shipments.csv`：出货量/产能/隐含 ASP/证据等级（纯数量事实）
- `company_segment_revenue.csv`：分部收入事实（金额/同比/毛利率/mapping_scope；mixed_scope 不挂 cell 防误归属）
- `out/全景.html`、`out/参与识别.html`：可视化（渲染中，见下）
- `tmp/daily/*.txt`：每日增量日报
- `docs/plans/2026-08-12-status-report.md`：项目内部状态报告（待决事项清单）
