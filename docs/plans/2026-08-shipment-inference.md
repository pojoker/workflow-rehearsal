## 3. 工序（复用判定闸标准工序）

1. 脚本预筛：从 corpus 抽各公司营收/型号/产能句子（grep 候选段）
2. 子代理并行起草推导行（五锚齐备草稿）
3. 闸主逐条机械复核：引语子串验证 + 推导式重算 + 海关上限检 ±30% 发布闸
4. 落表 + `scan.py --check` + 重渲（若渲染器需要读 shipments.csv 展示，另议；首版不渲染，纯数据层）
5. commit（产出格式：+N点 +M边 空格A/B 驳回K + SE 新增数）

## 4. 校准机制（接上现有节奏）

- 日更日报已含投关表/公告增量：凡命中在册 SE 行的收入/出货新披露 → 校准列回算
- 半年报季（2026-08 底起）：全量校准窗口
- 海关月度序列更新（85177950 次月数据）：上限检重跑

## 5. 明确不做

- 不推利用率、不推理论产能产值、不发市场份额、不做投资价值判断
- 情景行不进任何"基准"汇总；渲染层若展示推断数必须带"推断/C 级"水印式标注
- 未落地规则（FCC 草案）永不进基准表

## 5a. 设计对齐补丁（2026-08-10，codex 验收 P1 裁决后）

- **B 级例外**：年报产销表"量价齐露"的直接披露行可标 B（单一硬证据）；"推断永不进 A/B"仅约束推断行。
- **情景行锚豁免**：scenario-* 行（D 级）的收入/ASP/产能锚可标"不适用"，但海关锚或情景来源锚必须存在。
- **单位枚举扩展**：只/颗/件 + 万只/万个/万美元（流向额行专用，推导式须注明"非只数"）。

### SE004（撤表） Coherent MOD1 FY2025（截至 2025-06-30）

- 原始输入：Networking 分部营收 $3,421M(+49%)（锚：https://www.sec.gov/Archives/edgar/data/820318/000082031825000014/iivi-20250630.htm ）
- 原始假设：模块收入占比 60%–75%（无一手锚——10-K 表明该分部同时含 components/modules/subsystems 与 datacom/telecom 多类）；ASP 带 $600–900（无披露锚，macro_evidence 无对应 claim）
- 原始公式：出货量 = $3,421M × 模块占比 ÷ ASP；极值 $3,421M×60%÷$900≈228万 至 $3,421M×75%÷$600≈428万；原误取区间端点算术中点 330 万只
- codex 重算参考：极值约 228–428 万只；占比中点 67.5% × ASP 中点 $750 得中枢约 308 万只
- 锚失效说明：模块占比与 ASP 均无可定位一手锚；按裁决不得保留点值

### SE005（撤表） Lumentum MOD1 FY2025（截至 2025-06-28）

- 原始输入：Cloud & Networking 分部净收入 $1,410.8M（锚：https://www.sec.gov/Archives/edgar/data/1633978/000162828025040830/lite-20250628.htm ）
- 原始假设：模块占比 50%–65%（无一手锚——分部同时含 chips/components/modules/subsystems 及接入/城域/长途/海缆产品）；ASP 带 $600–900（同上无锚）
- 原始公式：出货量 = $1,410.8M × 占比 ÷ ASP；极值应为 $1,410.8M×50%÷$900≈78万 至 $1,410.8M×65%÷$600≈153万（原误写 90–150 万）；原误取 120 万只
- codex 重算参考：极值约 78–153 万只；中枢约 108 万只
- 锚失效说明：同上；裁决注记"不得仅通过放宽/平移无锚假设带修补算术"
