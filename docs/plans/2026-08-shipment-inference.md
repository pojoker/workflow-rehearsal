## 0. 目标产物

`shipments.csv`（账本新推断层）：公司级期间出货量推断行，等级封顶 C，全推导链锚定。

表头（冻结）：

```
row_id,公司,cell_id,期间,出货量,单位,推导式,收入输入,收入锚,ASP输入,ASP锚,海关上限检,海关锚,产能天顶检,产能锚,证据等级,情景标记,校准实际值,误差,校准日期,检索日期
```

字段规则：
- row_id = SE###（与 KN/MC/RB/P/E 编号族并立）
- 单位枚举：只/颗/件（纪律 7 同款）
- 证据等级：A/B 禁用，C=基准推断行，D=情景行
- 情景标记：base / scenario-FCC（后续可扩）
- 五锚缺一不入表；单值 ASP 一票否决

## 3. 工序（复用判定闸标准工序）

1. 脚本预筛：从 corpus 抽各公司营收/型号/产能句子（grep 候选段）
2. 子代理并行起草推导行（五锚齐备草稿）
3. 闸主逐条机械复核：引语子串验证 + 推导式重算 + 海关上限检 ±30% 发布闸
4. 落表 + `scan.py --check` + 重渲（若渲染器需要读 shipments.csv 展示，另议；首版不渲染，纯数据层）
5. commit（产出格式：+N点 +M边 空格A/B 驳回K + SE 新增数）

## 4. 校准机制（接上现有节奏）

- 日更日报已含投关表/公告增量：凡命中在册 SE 行的收入/出货新披露 → 校准列回算
- 半年报季（2026-08 底起）：全量校准窗口
- 海关月度序列更新（85177950 次月数据）：上限检重跑

## 5. 明确不做

- 不推利用率、不推理论产能产值、不发市场份额、不做投资价值判断
- 情景行不进任何"基准"汇总；渲染层若展示推断数必须带"推断/C 级"水印式标注
- 未落地规则（FCC 草案）永不进基准表
