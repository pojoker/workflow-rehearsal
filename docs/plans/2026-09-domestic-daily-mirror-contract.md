# 国内日更镜像契约（OpenCode 工包）

## 目标

复刻 `corpus/_daily_update.py` 的研究工作流语义，而不是实现泛新闻列表。新任务必须读取现有研究账本作为只读输入，并把所有运行状态、抓取内容和日报写入独立 `state_root`；不得修改源仓库的 `corpus/`、`tmp/daily/` 或任何 canonical 文件。

## 必须保持的业务行为

1. 关注公司集合保持原逻辑：`triage.csv` 中 `待判` 公司，加 `points.csv` 中 `生产中/在建` 公司，再加 `_restart_watchlist.csv` 的 `日更` 车道代码；国内 adapter 只接受六位 A 股代码，共享宇宙中的海外标识交给 `calls.daily_discovery`。
2. 投关表：查询巨潮 `relation/category_dyhd_szdy` 和 `fulltext/投资者关系` 最近三天；宇宙内 PDF 下载并转文本，宇宙外只生成光通信关键词补录候选，不自动入池。
3. 互动问答：每次从 `2023-01-01` 请求全量快照；以源仓库已有 `qa.jsonl` 和镜像历史快照的并集为基线，按 `index_id` 合并，只增不减。严禁改成 14 天窗口，严禁覆盖源仓库快照。
4. 公告流：只对关注公司取最近三天，标题过滤保持原 `ANN_PAT`：重大合同、向特定对象、定增、业绩预告、业绩快报、问询、回复、收购、资产重组。
5. 重启监视：新投关文本做触发词内容级匹配；公告按公司提示；互动问答增量提示人工过内容。输出明确说明“机械匹配，不构成判定”。
6. `scan`：用源仓库只读基线加镜像内新增 IR/QA 构造隔离视图，取得完整召回队列；按 `公司|cell` 比较 `queue-latest.txt`，生成新增/消失差分。不得导入或写回源仓库。
7. 月度分母重筛：保持逐家公司核验、只报 diff、不改 `_frozen.csv`；401/token 不可用时静默降级并在日志说明。标记文件只能写入 `state_root`。
8. 日报为 `.txt`，栏目、判定闸建议和原脚本一致：语料、投关表、互动易、公告流、重启复核、召回差分、校验、补录候选、月度分母差分、日志。

## 隔离与接口

- 提供可测试 CLI，建议：`python3 -m domestic_daily run --source-root <repo> --state-root <dir> --date YYYY-MM-DD`。
- `source_root` 全程只读；运行前后对受保护路径做内容指纹或状态核验，发现写入立即失败。
- `state_root` 保存 `daily/YYYY-MM-DD.txt`、`daily/queue-latest.txt`、`daily/queue-prev.txt`、IR/QA 镜像、月度标记、结构化 manifest/log。
- 同一天重复运行必须幂等；中途失败不能破坏上一次完整快照，采用锁、临时文件和原子替换。
- 网络调用必须可注入/fixture 化，测试不得依赖公网。
- 不安装 cron，不修改当前调度。

## 验收

1. 单元/集成测试覆盖关注公司集合、QA 全量并集不减、公告过滤、重启匹配、scan 全队列差分、401 降级、原子写与锁。
2. 测试证明源仓库受保护路径运行前后字节不变。
3. 离线 fixture 运行两次，日报和 manifest 在排除运行时长等非确定字段后字节一致。
4. `python3 scan.py --check` 在源基线上仍通过。
5. README 说明与原 `corpus/_daily_update.py` 的逐项映射、隔离目录和未来调度命令。

完成后运行测试并提交到当前分支；不要改动别的工作树，不要安装或启动定时任务。
